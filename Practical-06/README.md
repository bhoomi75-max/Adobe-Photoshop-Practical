Objective:
To learn how to design an attractive promotional poster using Adobe Photoshop.

Tools Used:

* Text Tool
* Move Tool
* Shape Tool
* Brush Tool
* Layers
* Layer Styles

Procedure:

1. Open Adobe Photoshop and create a new document.
2. Choose a suitable background for the poster.
3. Add shapes and images related to the promotion.
4. Use the Text Tool to add a heading and promotional message.
5. Adjust the size, color, and font of the text.
6. Arrange all elements properly using the Move Tool.
7. Apply effects such as Drop Shadow or Outer Glow.
8. Adjust colors and spacing to make the poster attractive.
9. Save the project in PSD format.
10. Export the final poster as a JPG or PNG image.

Result:
A promotional poster was successfully designed using Adobe Photoshop.

Conclusion:
I learned how to create an attractive promotional poster using text, shapes, images, layers, and effects in Adobe Photoshop.
