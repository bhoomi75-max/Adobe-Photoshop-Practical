Objective:
To learn advanced selection techniques and color correction using Adobe Photoshop.

Tools Used:

* Quick Selection Tool
* Magic Wand Tool
* Lasso Tool
* Adjustment Layers
* Layer Mask
* Brightness/Contrast
* Hue/Saturation

Procedure:
1. Open Adobe Photoshop.
2. Open a photograph containing a clear subject.
3. Select the subject using the Quick Selection, Magic Wand, or Lasso Tool.
4. Refine the selection to make the edges clean.
5. Create at least two adjustment layers.
6. Adjust Brightness/Contrast, Hue/Saturation, or Color Balance.
7. Change the color or appearance of the subject or background.
8. Use a Layer Mask to control the adjustments.
9. Compare the original and edited photographs.
10. Save the project in PSD format and export the final image as JPG.

Result:
The photograph was successfully edited using advanced selection tools, color correction, and adjustment layers.

Conclusion:
I learned how to select subjects, correct colors, and edit photographs using adjustment layers and masks in Adobe Photoshop.
