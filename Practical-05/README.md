Objective:
To learn how to use filters, effects, custom brushes, and blending modes in Adobe Photoshop.

Tools Used:

* Brush Tool
* Filter Gallery
* Blending Modes
* Layer Styles
* Eraser Tool

Procedure:

1. Open Adobe Photoshop and create a new document.
2. Import a photograph or create a simple design.
3. Apply suitable filters to the image.
4. Use the Brush Tool to add creative effects.
5. Select different blending modes to change the appearance of layers.
6. Apply effects such as Drop Shadow or Outer Glow.
7. Adjust the colors and opacity to improve the design.
8. Review the final composition.
9. Save the project in PSD format.
10. Export the final image in JPG format.

Result:
The design was successfully created using filters, effects, custom brushes, and blending modes in Adobe Photoshop.

Conclusion:
I learned how to apply filters, create artistic effects, use brushes, and work with blending modes in Adobe Photoshop.
