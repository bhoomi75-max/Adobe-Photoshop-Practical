Objective

To learn layers and layer masks by creating a creative travel poster in Adobe Photoshop.

Tools Used

* Adobe Photoshop
* Move Tool
* Transform Tool
* Layer Mask
* Text Tool
* Drop Shadow

Procedure

1. Open Adobe Photoshop and create a new document.
2. Import at least three photographs.
3. Place each photograph on a separate layer.
4. Rename the layers according to the images.
5. Use the Move and Transform tools to adjust image placement and size

Result:
A creative travel poster was successfully created using layers, masks, photographs, and text in Adobe Photoshop
