Practical 02 – Photo Editing and Basic Retouching

Name: Bhoomi Agarwal
Roll No.: 25260150
Course: Desktop Publishing – UAC012P

Objective

To learn photo editing and basic retouching in Photoshop.

Steps

1. Open the photograph in Photoshop.
2. Adjust brightness and contrast.
3. Correct the colours.
4. Remove unwanted spots using retouching tools.
5. Smooth the skin slightly.
6. Apply slight sharpening.
7. Save the final image as JPG and the project as PSD.
